```text
eingonpwint@Lenovo:~$
```

| Part | Meaning |
|---|---|
| `eingonpwint` | Current user |
| `Lenovo` | Computer hostname |
| `~` | Current user ရဲ့ Home directory |
| `$` | Normal user |
| `#` | Root user ဖြစ်လေ့ရှိ |

| Command | Purpose |
|---|---|
| `whoami` | Current user ကြည့်ရန် |
| `id` | Current user's UID, GID နှင့် groups ကြည့်ရန် |
| `id testuser` | `testuser` ရဲ့ UID, GID နှင့် groups ကြည့်ရန် |
| `pwd` | Current directory path ကြည့်ရန် |
| `hostname` | Computer hostname ကြည့်ရန် |
