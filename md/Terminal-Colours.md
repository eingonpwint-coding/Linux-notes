## 15. Terminal Colours

ပုံမှန်အားဖြင့်—

| Colour | Possible Meaning |
|---|---|
| Blue | Directory |
| Green | Executable file |
| Cyan | Symbolic link |
| White | Normal file |

Terminal colour က theme နဲ့ `LS_COLORS` setting ပေါ်မူတည်နိုင်ပါတယ်။

Permission အမှန်ကို colour နဲ့မဆုံးဖြတ်ဘဲ—

```bash
ls -l
ls -ld directory
```
