### Absolute Path and Relative Path

| Path | Meaning |
|---|---|
| `/home` | Absolute path — root `/` ကစရှာသည် |
| `home` | Relative path — current directory ကစရှာသည် |
| `~` | Current user ရဲ့ Home |
| `.` | Current directory |
| `..` | Parent directory |

ကိုယ့် Home မှာရှိနေချိန်—

```bash
cd home
```

လုပ်ရင် Linux က အောက်က directory ကိုရှာပါတယ်။

```text
/home/eingonpwint/home
```

System `/home` ကိုသွားလိုလျှင်—

```bash
cd /home
```
### Memory Note

```text
/home  = Root ကနေစရှာ
home   = လက်ရှိနေရာကနေစရှာ
~      = ကိုယ့် Home
.      = လက်ရှိ directory
..     = အပေါ် directory
```
